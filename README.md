# TodoList

Una aplicación sencilla para organizar tus tareas por carpetas y mantener un control visual de lo que tienes pendiente.

## Descripción

TodoList es un proyecto desarrollado con JavaScript y Webpack para gestionar tareas diarias, organizarlas por categorías y llevar un control de lo que está pendiente o completado. La app guarda la información localmente en el navegador, por lo que puedes usarla de forma rápida sin configurar un backend.

## Características

- Crear, editar y eliminar carpetas
- Agregar nuevas tareas dentro de cada carpeta
- Modificar o eliminar tareas existentes
- Marcar tareas como completadas o pendientes
- Filtrar tareas por estado y prioridad
- Guardado automático en localStorage
- Interfaz simple y fácil de usar

## Tecnologías

- HTML
- CSS
- JavaScript
- Webpack
